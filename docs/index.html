A personal AI assistant that runs on one home PC.

Ultron is a private chat assistant built from open-source parts. The language models run on a single consumer GPU, chats stay on the owner's machine, and the assistant can search the web, work in a sandbox, generate images and manage a Google Calendar.

View the repository How it fits together

What it is

Ultron is one person's assistant, set up and documented so it can be rebuilt from the repository. It is not a hosted service: there are no accounts to sign up for, and the only user is the owner.

Local

Models on your own GPU

A llama.cpp server runs the models natively on the PC. Nothing is sent to a cloud model provider.

Private

Only reachable by its owner

Every service listens on localhost. The chat UI is reached from a phone or laptop over a private Tailscale network, never the open internet.

Reproducible

Pinned, scripted, backed up

Container versions are pinned in Docker Compose, start-up runs from a script, and a daily backup keeps the last 14 copies.

How it fits together

The chat UI is the front door. Model requests go through a gateway to the local model server; tools give the assistant search, a sandbox, images and a calendar.

The stack

Every component is free and open source, and runs on one Windows PC with Docker Desktop.

PieceWhat it does
Open WebUIChat UI with login and history. Sign-ups are disabled; telemetry and community sharing are off.
llama.cpp serverRuns the models natively on the GPU in router mode with one model, Qwen3.6-35B-A3B, loaded at start-up and never swapped. API key required.
LiteLLM gatewayOne OpenAI-compatible endpoint in front of the model server, with keys and per-request token logs stored in Postgres.
SearXNGPrivate metasearch used for web search. No published port; only the chat UI can reach it.
Open TerminalThe agent's sandbox: a shell and files inside a container that sees only its own home folder and one workspace folder.
GPU broker + ComfyUIA small local broker unloads the chat model before an image job and frees ComfyUI's memory after it, so both share one GPU.
Google Calendar toolLets the assistant manage the owner's calendar from plain-language requests.
Prometheus, Grafana, Uptime KumaMetrics, an “Ultron” dashboard with GPU temperature and memory, and uptime alerts.
TailscalePrivate, encrypted access from the owner's own devices.

Models

Three names appear in the model picker. Speeds were measured on the owner's PC with a 12 GB consumer GPU.

Fast chat

ultron

Qwen3.6-35B-A3B, a mixture-of-experts model with 3B active parameters, a 49k context and thinking off. About 52–57 tokens/s with multi-token prediction; some expert layers run on the CPU. Loaded at start-up.

Reasoning

ultron-think

The same loaded model with step-by-step reasoning switched on. Same speed, with extra tokens per answer.

Agent

ultron-agent

The same loaded model with thinking off, for terminal and file work. Same speed; switching to it does not swap models.

Features

What the assistant can do today.

  • Local chat with a fast model and a reasoning mode, switchable per chat.
  • Agent model for multi-step work, with native function calling and a limit of 8 tool rounds per answer.
  • Web search through a private SearXNG instance; fetched pages can't point the assistant at the local network.
  • Code interpreter that runs Python in the browser (Pyodide), never on the PC.
  • Agent sandbox with a shell and a workspace folder, cut off from the database, gateway and monitoring containers.
  • Image generation and editing through ComfyUI workflow templates, with parameters checked before a job is queued.
  • GPU sharing: the chat model steps aside for image jobs and reloads by itself on the next message.
  • Google Calendar: add, list, move and delete events by asking in plain language.
  • Access from anywhere on the owner's devices over Tailscale, with HTTPS.
  • Monitoring and alerts for token usage, GPU temperature and memory, and service uptime.
  • Daily backups of chats, dashboards, gateway data and secrets, 14 copies kept.
  • Test scripts for tool use, model modes and agent-model benchmarks.

Calendar assistant

A Google Calendar tool lets the assistant handle events the way you would describe them to a person.

Haircut at 1pm Sunday, remind me.
Added “Haircut” on Sunday, 1:00–2:00 pm, with a reminder before it starts.
Move it to 3.
Moved to 3:00–4:00 pm.
  • Adds, lists, moves and deletes events from plain-language requests.
  • Asks when the time is missing instead of guessing.
  • Fills in a typical end time when only a start is given.
  • Sets reminders and warns about clashes with existing events.
  • Changes or deletes only events the assistant created itself.
  • Access is limited to calendar events; see the privacy policy.
