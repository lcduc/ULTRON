Privacy policy

Last updated: 17 November 2026

In short: Ultron runs on its owner's own computer for its owner only. Calendar data is processed there by a local language model and is never sold, shared or sent to any other service.

What Ultron is

Ultron is a personal assistant that runs on its owner's own computer. It is not a public service: there is no sign-up, and only its owner signs in to it or connects it to their accounts.

Google Calendar

Ultron can connect to its owner's Google Calendar so the assistant can manage events on request.

  • What it can access: calendar events only, through the scope https://www.googleapis.com/auth/calendar.events. It does not request access to email, contacts, files or any other Google data.
  • How it is used: Ultron reads events to answer the owner's questions, and adds, changes or deletes events only when the owner asks it to.
  • Where it is processed: calendar data is processed on the owner's computer by a locally running language model.
  • Sharing: calendar data is not sold, shared, or sent to any other service.
  • Storage: the access token is stored only on the owner's computer.

Ultron's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. After that, Ultron can no longer read or change the calendar.

This website
